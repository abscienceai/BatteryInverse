# Data source and license notice

This source package includes a **compact derived cell-level table** for the BatteryInverse benchmark. It is not a redistribution of the original large raw battery test archives. The table has 567 rows and 38 columns and was assembled from BatteryML-derived and BatteryLife-selected sources.

**Data-license warning:** Original data providers retain their rights. An MIT license for scripts does **not** cover third-party battery data, processed measurements, metadata or source-specific conditions automatically. Before publishing the `data/` CSV, check whether each upstream dataset permits redistribution of transformed/derived measurements and provide the required attribution. If a provider's terms cannot be confirmed, publish only permitted summaries and obtain permissions first.

The upstream versioned input manifest and original raw-file formats are not fully verified from the compact package; do not claim exact raw-file-level reconstruction without that information. The optional source-processing scripts refer to original provider files not included in this repository.

No raw archives, proprietary instrument records or manuscript source/PDF files are included.
